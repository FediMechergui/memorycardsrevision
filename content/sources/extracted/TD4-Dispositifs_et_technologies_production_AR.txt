EXERCICE 3
On souhaite réaliser une application de réalité augmentée en utilisant le SDK Vuforia et le moteur
de jeu Unity 3D. L'idée de l'application est d’aider ses utilisateurs à apprendre les formules

géométriques (surface, périmètre, etc.) associées aux primitives 3D (cube, cylindre, sphère, etc.)

En scannant un marqueur contenant la forme 3D, l’application augmente ce marqueur par des
données textuelles pour les formules géométriques et un objet 3D de cette forme pour voir ses

différentes caractéristiques (largeur, hauteur, longueur, rayon, etc.), qui seront schématisées sur

l’objet.

    1.  Quelle est la configuration nécessaire à faire pour intégrer Vuforia Engine à Unity 3D ?
    2.  Décrire brièvement les étapes nécessaires à la création de cette application sachant qu’on
       va se limiter à deux marqueurs pour un cube et une sphère.
    3.  Quelle est la technique de reconnaissance de marqueurs utilisée au niveau de Vuforia ?
    4.  Quel type de tracking sera utilisé dans cette application ?

    5. On souhaite maintenant animer les modèles 3D lors de leur augmentation sur les images
         cibles.
       a)  Ecrire un script C# "Animation.cs" permettant de faire tourner l’objet 3D d’un angle 7
           radian suivant l'axe Y.
       b) Ajouter le code nécessaire pour changer la couleur de l’objet en cliquant sur la touche

          « A ».
